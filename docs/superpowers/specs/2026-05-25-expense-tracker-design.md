# 花销追踪 Web 应用设计

## 概述

一个支持电脑和手机浏览器的花销追踪 Web 应用，支持多人协作记账，数据导出为 CSV 文件。

## 技术决策

### 存储方式
- **本地存储 + CSV 导入/导出**
- 使用 IndexedDB 存储结构化数据，支持离线使用
- CSV 格式便于 Excel 查看和数据备份
- 多设备同步需要用户手动导出/导入

### 前端技术栈
- 纯 HTML + CSS + JavaScript（无框架依赖，便于部署）
- CSS Grid/Flexbox 实现响应式布局
- 单页应用架构，Tab 导航切换视图

### 数据模型
```
记账本 (Ledger)
  - id: string
  - name: string
  - createdAt: timestamp

支出记录 (Expense)
  - id: string
  - ledgerId: string
  - content: string (内容)
  - amount: number (金额，元，保留两位小数)
  - category: string (分类)
  - location: { province: string, city: string } (地点，默认重庆)
  - date: string (YYYY-MM-DD)
  - createdBy: string (创建人)
  - createdAt: timestamp
```

### 预设分类
- 餐饮、购物、交通、居住、医疗、娱乐、旅行、教育、人情、其他

## 界面设计

### 配色方案
- **温暖奶油色**
- 背景色: #F5E6D3
- 强调色: #D4A574
- 文字色: #8B4513

### 布局方案
- **Tab 导航**
- 手机端：底部 Tab 栏
- 电脑端：左侧侧边栏
- 四个 Tab：记账本、记一笔、统计、我的

### 日历视图
- 月份日历展示，有支出的日期高亮显示
- 点击日期查看/编辑当日明细
- 底部/侧边显示本周/本月/本年汇总

## 页面结构

### 1. 记账本选择页
- 显示已创建的记账本列表
- 新建记账本按钮
- 选择记账本后进入主界面
- 支持设置默认记账本

### 2. 记一笔页面
- 快速添加支出表单
- 字段：内容、时间（默认当天）、分类（下拉选择）、地点（省市选择，默认重庆）、金额（输入框，两位小数）、备注（可选）
- 保存后显示成功提示，可继续添加

### 3. 统计页面
- 日历视图为主
- 切换月份显示
- 按分类/时间维度筛选
- 导出 CSV 按钮（按当前筛选条件）

### 4. 我的页面
- 切换记账本
- 管理记账本（新建、删除、重命名）
- 导出/导入数据
- 关于

## 交互设计

### 便捷性考虑
- 记一笔页面作为默认入口（或第一个 Tab）
- 时间字段默认当天
- 地点默认重庆市
- 金额输入支持粘贴和快捷计算
- Tab 切换保留页面状态
- 输入框获焦时自动弹出键盘（手机端）

### 多用户支持
- 每次提交记录可选择或输入用户名
- 用户名自动记忆
- 可按用户筛选统计

### 错误处理
- 必填字段验证
- 金额格式校验
- 网络错误时提示重试
- 表单错误高亮显示

## 响应式适配

### 手机端 (< 768px)
- 单列布局
- 底部 Tab 导航
- 表单垂直排列

### 电脑端 (>= 768px)
- 左侧侧边栏 + 右侧主内容区
- 表单可双列布局
- 日历格子更大
